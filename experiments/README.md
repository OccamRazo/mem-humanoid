# 实验管理

每个实验目录使用 `EXP-YYYYMMDD-short-name/`，日期为实验立项日期，短名称使用简洁的小写英文和连字符。不同研究问题不要混在同一实验目录中。

每个实验至少包含一个 `README.md`，建议按以下模板记录：

```markdown
# EXP-YYYYMMDD-short-name

## 目标
## 对应假设
## 变更内容与对照组
## 数据版本与本地位置说明
## 模型、系统与依赖版本
## 配置与随机种子
## 环境与硬件
## 运行命令
## 指标与统计方法
## 独立运行记录
## 结果
## 异常、负面结果与限制
## 结论及证据强度
## 产物与图表追溯
## 后续工作
```

运行要求：

- 配置、代码、数据划分和关键依赖必须可定位到精确版本；
- 固定并记录所有可控随机种子，结果按独立运行保存；
- 不修改原始结果，不删除失败运行；如需修正，新增记录并说明原因；
- 大型日志、视频、传感器数据和权重不进入 Git，只提交摘要、校验信息和复现路径；
- 报告实际运行的检查；环境不具备时明确写 `未运行` 及原因。
