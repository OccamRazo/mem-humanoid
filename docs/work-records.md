# 工作记录与本地产物

本文件规定小型、可版本管理的记录如何关联复现输入、结论和本地产物。目录约束见 [experiments/AGENTS.md](../experiments/AGENTS.md)，项目要求见 [项目约定](project-guide.md)。

## 记录放在哪里

- 研究结论和证据放在对应研究文件；执行计划放在 `docs/plan/`；实际实验、复现和审计放在所属实验目录。
- 每项实验以 `README.md` 为入口。独立运行使用独立 ID，在 `records/<run-id>.md` 中保存小型记录；只有开始记录运行时才创建 `records/`。
- 冻结配置、清单、校验和等小型复现输入可放在实验 `configs/`、`manifests/`。一次性脚本、测试和专用依赖放在该实验 `code/`。
- 大型视频、原始帧、权重和完整日志保留在设备本地。可使用仓库外目录，或实验内已忽略的 `outputs/<run-id>/`；记录中写明设备、位置、版本和可用性。
- 不把小型记录放在被忽略的 `runs/`、`run-*/`、`outputs/` 等目录。当前忽略规则见 [.gitignore](../.gitignore)；新增嵌套产物位置时实际检查覆盖。

## 实验入口

在实验实际立项时按真实开始日期创建 `EXP-YYYYMMDD-<short-name>/README.md`，保留既有实验名。入口至少记录以下内容，可按实验复杂度合并标题，但不能省略关键事实：

```markdown
# EXP-YYYYMMDD-<short-name>

## 目的、状态与来源计划
## 假设、变更内容、对照组与失败判据
## 代码提交、数据版本与划分、模型和依赖版本
## 环境、硬件、配置与随机种子
## 复现命令与执行目录
## 指标、统计方法与样本排除规则
## 独立运行索引与结果位置
## 结果、异常、负面结果与限制
## 结论及证据强度
## 产物与图表追溯
## 后续工作
```

没有结果时标注“未运行”，未知版本写 `unknown` 并说明待补项。退休实现需在入口明确标记，链接保留的结果、审计、源代码提交和历史检出方法；不将其默认为后续开发基础。若迁移代码，提供原路径到新路径映射，但不重写历史运行中的路径或哈希。

## 单次运行记录

每条运行记录应足以让另一位研究者定位证据并判断可否复现：

| 字段 | 要求 |
| --- | --- |
| 标识与关系 | run ID、实验、来源计划/假设；若重跑或审计，链接前次记录并解释差异 |
| 时间与执行者 | 完整日期、时区、执行设备及操作者/工具；不要用 Git 时间代替实际运行时间 |
| 状态 | 计划中、运行中、完成、失败或取消；未执行检查写 `not run` 和原因 |
| 代码与环境 | 提交 SHA、运行时未提交差异的位置（如有）、系统、硬件和关键依赖 |
| 输入与配置 | 数据/模型版本、清单和校验和、划分、参数、可控随机种子 |
| 复现方式 | 执行目录、完整命令、准备步骤和必要环境变量名称，不记录密钥值 |
| 样本与结果 | 样本量、排除项、失败数、指标及统计方法、简洁结果和原始输出位置 |
| 解释与边界 | 已验证发现、推断、限制、后续问题；图表引用数据和生成方法 |
| 本地产物 | 产生设备、绝对路径或明确的根目录变量、文件清单/哈希、当前设备可用性及最近核验情况 |

保留原始及失败记录。更正、重评和替代运行独立保存并互相链接，不能把预期指标填成实际结果，或用新的路径和数值覆盖冻结证据。

## 忽略规则核验

下面的路径仅用于检查规则，不代表已有实验或运行；命令在仓库根目录执行：

```bash
git check-ignore -v --no-index experiments/EXP-YYYYMMDD-example/outputs/run-001/frames/frame.png
git check-ignore -v --no-index experiments/EXP-YYYYMMDD-example/records/run-001.md experiments/EXP-YYYYMMDD-example/configs/run-001.yaml
```

第一条应显示产物命中的忽略规则；第二条应无输出并返回 1，表示记录与配置未被忽略。新增路径须替换为实际位置检查，不能仅依赖示例。Git 交接只传递小型记录与已提交输入，产物在其他设备是否可用需独立确认。
