# 园区机器人巡检demo数据采集

## 1.  背景

### 1.1  记忆能力概述

记忆能力目前分为5级，L1 工作记忆维持与整合，L2 情景记忆构建与检索，L3 记忆巩固与图式化，L4 记忆驱动的重构与预测，L5 元记忆调控与终身优化。

L1：在有限时空窗口内维持高保真感官表征，并整合局部时间范围内的物体、关系、顺序与空间布局。

L2：将离散视觉事件组织为带有时间、空间和情境标签的长期记忆单元，建立事件之间的关联，形成可检索的经验轨迹。

L3：从大量具体经历中归纳稳定概念、规律、图式与世界知识，实现由事件记忆向抽象知识的压缩和泛化。

L4：主动调用已有记忆，完成过去重构、未来预测、反事实模拟和行动路径推演，支撑生成式决策与规划。

L5：监控和评估自身记忆状态，根据任务需求和信息价值，动态执行记忆强化、更新、重组与主动遗忘，并持续优化学习策略。

### 1.2  巡检机器人系统

宇树G1巡检机器人在园区内的固定范围进行巡检，正常情况沿固定路线巡检，如过遇到意外或异常，可以主动偏离预定路线进行检查或处理，之后再回到原本路线继续巡检。机器人本身仅根据极少量的规则开始巡检，在巡检过程中不断记录环境、物体、人物、事件，逐渐熟悉整个巡检区域，并总结出关于园区的一些规律，同时根据预定的少量规则判断异常，并进行处理。

### 1.3  数据目标

当前数据采集考虑评估机器人记忆系统的L1工作记忆的维持与整合、L2情景记忆的构建与检索、L3记忆巩固与图式化前3层记忆能力。暂不考虑L4，L5记忆能力。



## 2.  数据要求

### 2.1  L1工作记忆的维持与整合

#### 内容要求

**对于物体**：在单次巡检过程中，存在一定数量的需关注的对象；在某些功能区域，比如消防设施存放点，需有较密集的对象，且分布范围较广，无法同时出现在一个视野中。记忆系统可以统计这些对象属性，建立起这些对象之间的关联。

**对于事件**：在单次巡检过程中出现一些时序事件。记忆系统可以记录这些事件的内容，发生时序，并且根据需要进行处理。

### 2.3  L3记忆巩固与图式化

#### 内容要求

**对于环境**：1. 存在一些未显式定义的功能区域，固定存放某些设备，设备状态可以变化。系统可以根据多次稳定的观测得出区域的功能。

**对于事件**：1. 固定时间点或者固定地点出现相同的事件，比如班车发车，环卫清扫，某人饭后散步，某人上班等等。系统可以根据这些观测得出统计规律，知识。2. 对于异常事件，请专业人员进行处理，记录处理过程。系统根据记录总结异常判定标准与异常处理流程。
