# 文献与证据

文献记录服务于具体研究问题，不以堆积论文数量为目标。每条记录建议包含：

- 完整题目、作者、年份、稳定链接、DOI 或 arXiv 标识；
- 研究问题、场景、数据、方法、对照和指标；
- 与本项目直接相关的结果及其适用边界；
- 局限、潜在偏差和未解决问题；
- `事实`、`作者观点` 与 `本项目推断` 的明确区分；
- 对应想法、假设或实验的相对路径。

需要横向比较时可增加证据表，但表中的关键数字必须能够追溯到原文位置或公开结果。
