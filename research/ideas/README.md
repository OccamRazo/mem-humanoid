# 想法与提案

每个独立想法使用一个 Markdown 文件，建议至少记录：

- 背景与要解决的问题；
- 为什么记忆是必要变量，而不是一般感知或规划问题；
- 核心机制与替代解释；
- 预期收益、成本、风险和失败模式；
- 支持与反对证据；
- 如何转化为可证伪假设；
- 当前状态：`探索中`、`进入假设`、`暂停` 或 `否定`。

想法进入实验前，应在 `research/hypotheses/` 中形成明确假设；不要直接把提案描述当作已验证结论。
