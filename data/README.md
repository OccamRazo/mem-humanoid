# 数据管理

本目录只保存数据说明、采集协议、划分、模式定义、小型元数据和校验信息。大型原始传感器数据、派生缓存、视频、点云、模型输入产物及包含敏感信息的数据不提交到 Git。

每个数据源至少记录：

- 名称、版本、负责人或来源、授权与许可；
- 采集场景、时间范围、设备和关键参数；
- 模态、时间同步方式、坐标系和数据结构；
- 标注规范、质量检查、已知缺失和偏差；
- 训练/验证/测试划分规则及防止时间或场景泄漏的措施；
- 本地目录约定、获取或生成步骤、文件清单与校验和；
- 隐私、脱敏、访问权限、保留期限和删除流程。

建议大型数据在各设备上使用仓库外的明确路径，并通过版本清单而不是绝对路径建立可复现关联。任何跨设备复制应采用经过批准的存储渠道，不通过 Git。
